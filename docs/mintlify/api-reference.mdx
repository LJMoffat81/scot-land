---
title: "API Reference"
description: "Public HTTP endpoints, read from the FastAPI routes in backend/api."
---

**Base URL:** `https://www.scot-land.scot/backend`

All endpoints are `GET`, need no key and return JSON unless noted. Viewport layers take a WGS84 bounding box: `south`, `west`, `north` and `east` are required, and `max_features` is optional (the server caps it). An unloaded layer returns `503` with an explanation.

<Warning>No endpoint listed here returns modelled money figures from the commons engine. Tax-scenario and modelled valuation endpoints are withheld: see "Not public" at the bottom of this page.</Warning>


## Health and catalogue

| Method | Path | Params (* required) | Description |
|---|---|---|---|
| `GET` | `/api/catalog.json` | — | Api Catalog |
| `GET` | `/downloads` | — | Index of freely licensed layers and official sources. |
| `GET` | `/health` | — | Liveness plus honest dependency status. Never 500s; DB down is reported, not hidden. |
| `GET` | `/layers/catalog` | — | Open land platform layer list (brief + live/gap status). |
| `GET` | `/platform/gaps` | — | Visible register gaps — first-class product, not hidden. |

## Search and places

| Method | Path | Params (* required) | Description |
|---|---|---|---|
| `GET` | `/api/place-stack.json` | `zone`, `lat`, `lng` | Place view per-hectare stack (Natural capital ledger). |
| `GET` | `/api/place.json` | `pc`, `lat`, `lng` | Place card download (place_card_v1). No modelled money figures. |
| `GET` | `/geocode/postcode` | `q`* | Geocode Postcode |
| `GET` | `/place` | `q`* | Find where to open the map. A title miss is not a rent and not a ScotLIS call. |
| `GET` | `/platform/place` | `lat`*, `lng`*, `postcode` | Public place card for one clicked spot (place_card_v1). |
| `GET` | `/postcode/{postcode}` | `postcode`* | Public postcode → centroid only. Modelled valuation routes stay under `/internal/`. |

| `GET` | `/layers/context/seabed/at` | `lat`*, `lng`* | Published Crown Estate Scotland lease at a point. |

| `GET` | `/layers/open/localities/at` | `lat`*, `lng`* | Locality containing a point (when PostGIS ingest is loaded). |
| `GET` | `/layers/open/settlements/at` | `lat`*, `lng`* | Settlement containing a point (when PostGIS ingest is loaded). |
| `GET` | `/layers/parcels/at` | `lat`*, `lng`* | Cadastral parcel polygon under a point (GeoJSON FeatureCollection). |

## Not public

These routes exist in the code but are **not** public data products. They are either withheld rent and scenario outputs (blocked until review) or operational endpoints:

`/layers/georgist/surface-rent`, `/layers/georgist/resource-rent`, `/layers/georgist/eco-rent`, `/georgist/wealth`, `/layers/councils`, `/api/roll.json`, `/api/roll.csv`, `/api/vdl-councils.json`, `/address`, `/sales/status`, `/signoff`, `/config`, `/boundaries/glasgow-ward-18`, and everything under `/internal/` (which needs a token and is never public).

The machine-readable schema is at `/backend/openapi.json`.
