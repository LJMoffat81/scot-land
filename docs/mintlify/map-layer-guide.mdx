These are the layers that were live on 13 October 2026. Flood and woodland row counts are regenerated with `python scripts/data/regen_layer_guide_counts.py` from PostGIS when loaded (else WFS hits / the #57 baseline). They change when sources are refreshed. SEPA flood vintage is **2025-02-25** (Flood Maps v3.0 release notes).

**Quality tags**

- `official`: loaded as published by the source body.
- `converted`: reprojected or reshaped from the official download (e.g. geodatabase → GeoJSON). Geometry may be lightly simplified.
- `partial`: covers only part of Scotland.
- `context`: shown for information only. Never a rent.
- `point-proxy`: a representative point, not a boundary.

<Note>
Every layer listed here is under the **Open Government Licence v3.0**, and **none** of them is non-commercial. Any layer added later with a non-commercial licence will be marked **NC** in this table.
</Note>

## Not shown

- **Annual Ground Rent £ figures**: not published yet while calibration is checked. For now, figures are published at Data Zone level only, not for individual parcels, plots or addresses (market / proxy / shadow labels).
- **Public and Crown land holdings**: the licence is unverified, so this layer is hidden.
- **Private ownership / Sasine**: not open data.

Each layer's endpoint returns `503` with an explanation when it isn't loaded. It never returns made-up data.
